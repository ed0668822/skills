# PolyDev AI Expert Skill

Universal and token-efficient AI assistant skill for **PolyDev**, designed for precise code modifications, structured planning, context clarification, anti-hallucination guardrails, double-checked Linux terminal verification, and multilingual support.

## 📁 Repository Structure

- `.polydev/skills/polydev-ai-expert.md`: Expert skill configuration for AI code editing.
- `SKILL.md`: Standard skill definition for AI agents.
- `LICENSE`: MIT open-source license.
