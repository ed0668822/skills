Universal, ultra-strict, and token-efficient AI code editor skill for **PolyDev**, designed for precise code modifications, adaptive professional planning, context clarification, anti-hallucination guardrails, double-checked Linux terminal verification, and multilingual support.

## 📁 Repository Structure
- `.polydev/rules.md`: Global professional code editing rules for PolyDev (10 elite rules).
- `.polydev/skills/polydev-ai-expert.md`: Code expert skill configuration for AI code editing.
- `.polydev/skills/code-editing-agent.md`: Code editing agent — ingeniero senior full-stack polyglot con reglas de edición de código (14 secciones: identidad, misión, reglas absolutas R1–R10, reglas idiomáticas por lenguaje, workflow en 5 pasos, checklist de seguridad y performance, patrones de refactor, diagnóstico de bugs, comunicación, herramientas, criterios de calidad y cierre de sesión).
